# Personal Developer Portfolio

A responsive, dark, minimal personal portfolio built with HTML, CSS and vanilla JavaScript.

## 1. Open the project
- Extract the ZIP file.
- Open the `developer-portfolio` folder in Visual Studio Code.
- Open `index.html` with the Live Server extension, or open it directly in a browser.

## 2. Personalize before publishing
Search in `index.html` and replace:
- `Your Name` with your preferred display name.
- `your.email@example.com` with your email address.
- LinkedIn and GitHub URLs with your own profile URLs.
- The two project cards with projects you have actually completed.
- The skills list with skills you can confidently explain.
- Any location or education wording you want to change.

## 3. Add your profile photo
- Put your photo in the `images` folder.
- Name it `profile.jpg` (or use another image extension).
- In `index.html`, find `images/profile-placeholder.svg` and change it to `images/profile.jpg`.
- Use a clear, well-lit portrait image. Keep the image reasonably compressed for faster loading.

## 4. Publish with GitHub Pages
1. Create a GitHub repository named `developer-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, the `images` folder and this README.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the provided website URL.

## 5. Before submitting
- Test at mobile width (around 360px), tablet (768px) and desktop (1280px).
- Check every link and replace all placeholders.
- Confirm your profile image has meaningful alt text.
- Submit the live website link, GitHub repository link and a short note about one design decision you are proud of.

This project uses no framework or external JavaScript library. Google Fonts are loaded from Google Fonts; the page remains usable with fallback fonts if they are unavailable.
